DETR Object Detector

Live Demo

An interactive object detector that runs entirely in the browser — no backend. DETR, a detection Transformer (facebook/detr-resnet-50), is served as a quantised ONNX model through Transformers.js and executed client-side on WebAssembly. Drop in any photo and it draws a box around every object it recognises across 80 COCO categories, with an adjustable confidence threshold and a per-object confidence breakdown. Also ships as the original PyTorch + Gradio app.

Brain Tumor MRI Classification with a Vision Transformer

Built a custom Vision Transformer from scratch in PyTorch to classify brain MRI scans into four categories (glioma, meningioma, pituitary, no-tumor), exploring a transformer-based alternative to the CNNs conventionally used for medical image classification. Implemented the full ViT architecture — convolutional patch embedding, multi-head self-attention, and transformer encoder blocks — and structured the project as a modular, reproducible ML pipeline.
